Ro Zero is a fork of Noto Sans. It is a Modified Version of Noto Sans under the SIL Open Font License 1.1, not an original typeface. Outlines start from Noto Sans (including Noto Sans KR, JP, SC, Arabic, Hebrew, Thai, Devanagari, and Symbols). Each glyph is then shattered into about 100 stone-like shards with 30% crack gaps and straight fractures.

The family name is Ro Zero. It does not use the name Noto. Noto is a trademark of Google LLC. Styles run from Thin 100 through Black 900.
