Ro Zero is a fork of Noto Sans. It is a Modified Version of Noto Sans under the SIL Open Font License 1.1, not an original typeface. Outlines start from Noto Sans. Each glyph is shattered into about 100 stone-like shards with 30% crack gaps and straight fractures.

Coverage is Korean Hangul, English/Latin, and punctuation/symbols. The family name is Ro Zero. It does not use the name Noto. Noto is a trademark of Google LLC. Styles run from Thin 100 through Black 900. The specimen shows Bold 700.
