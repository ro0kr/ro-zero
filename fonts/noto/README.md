# Noto Sans (unmodified upstream)

These files are the **original Noto Sans** fonts this fork uses:

- Noto Sans (Latin)
- Noto Sans KR (Hangul)
- Noto Sans Symbols / Symbols 2 (punctuation and symbols)

Ro Zero is a Modified Version / fork. Do not ship these files as Ro Zero.
Built Ro Zero binaries are in `../ttf/`. Japanese, Simplified Chinese, Arabic,
Hebrew, Thai, and Devanagari Noto fonts are not used.

Downloaded by `../../sources/fetch_fonts.py` from the Google Fonts GitHub mirror.
