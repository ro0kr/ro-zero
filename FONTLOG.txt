FONTLOG
Ro Zero
======================================================================

This file provides detailed information on the Ro Zero Font Software.
This information should be distributed along with the Ro Zero fonts
and any derivative works.


Basic Font Information
----------------------------------------------------------------------

Ro Zero is a fork of Noto Sans (SIL Open Font License 1.1 Modified Version).
It is not an original typeface family. Outlines start from Noto Sans, then
each glyph is shattered.

It takes Noto Sans outlines, then shatters each glyph into about 100
stone-like pieces with 30% crack gaps and roughness 0 (straight cracks).
The shatter seed is the character code point. Corner rounding uses a
radius measured from Noto Sans Black 900.

Shipped fonts cover Korean Hangul, English/Latin, and punctuation/symbols.
They do not ship CJK ideographs, kana, Arabic, Hebrew, Thai, or Indic.

Upstream sources used for this Modified Version are Noto Sans, Noto Sans KR,
and Noto Sans Symbols. Japanese, Simplified Chinese, Arabic, Hebrew, Thai,
and Devanagari Noto fonts are not used.

The family name is "Ro Zero". It does not use the name "Noto".
"Noto" is a trademark of Google LLC.

Styles: Thin 100, ExtraLight 200, Light 300, Regular 400, Medium 500,
SemiBold 600, Bold 700, ExtraBold 800, Black 900. The catalog specimen
uses Bold 700.

Acknowledgements
----------------------------------------------------------------------

Noto Sans was designed by Monotype and Google as part of the Noto
project. Ro Zero keeps Noto’s metrics and Hangul/Latin/punctuation outlines as the
starting shapes, then replaces the filled shapes with shattered shards.

If you make modifications, add a changelog entry here.
