# Third-party notices

## Noto Sans fork

Ro Zero is a fork of Noto Sans (a Modified Version under OFL 1.1).
The family name is Ro Zero. It does not use the name Noto.
Shipped coverage is Korean Hangul, English/Latin, and punctuation/symbols.
